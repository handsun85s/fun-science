# 项目需求与验收

家里上小学的孩子想弄清一个科学现象时，可以用平板找到适合自己难度的实验，动手观察结果，完成任务和两道小考验，并在同一设备上接着学。

## 已确认的需求

- 优先用户是家里上小学的孩子，内容由浅入深覆盖 7～12 岁。家长提供设备和实际试用反馈。
- 核心入口是平板浏览器。当前可以通过 GitHub Pages 打开，也可由家中电脑在同一 Wi-Fi 下提供访问。用户曾报告平板看得到网页却听不到中文，后来确认局域网版本可以朗读。
- 每课保留动画、动手任务、知识点、两道小考验和中文朗读。本阶段完善操作连续性和教学内容，课程范围见 [README](../README.md)。
- 星星和答题状态按浏览器及网址保存。平板触控和声音以家长的实机反馈为准。

本次审核采用两项可调整的验收假设：用《认识钟表》检验搜索与答题恢复，用《雪鞋为什么不容易陷下去》检验预测与证据流程。两课是代表样例。等实际使用出现新卡点，再决定后续优先级。

## 核心流程验收

| 前提 | 操作 | 预期结果 | 验证方式 |
| --- | --- | --- | --- |
| 打开首页 | 搜索「认识钟表」，点击结果 | 进入对应实验并展示任务和两道题 | Chrome 操作 |
| 对照实验尚未运行 | 先选一个预测，再分别运行两种条件，按记录选结论 | 两行结果分开显示。缺少记录时不能完成。纠正错误结论后得星一次 | Chrome 操作 |
| 小考验答错一次 | 刷新，改选正确答案，再刷新 | 保留已尝试选项，纠正后得星，重复刷新不重复奖励 | Chrome 操作 |
| 当前设备无中文语音 | 点「听听为什么」 | 浏览器取得预生成 MP3 并开始播放 | Chrome 播放检查，平板确认实际出声 |
| 正在等待上一课的朗读启动或补读 | 切回首页 | 上一课的朗读不会迟到播放 | Chrome 模拟语音状态和时钟 |
| 使用家中的旧平板 | 打开首页，在一课内完成触控、答题及朗读 | 页面可见，控件可点，听得到声音 | 平板实机 |

## 后续范围

真实平板验收、健康与安全课的其余情境校核，以及旧课程中代表性任务的操作抽样按实际反馈安排。跨设备进度同步需要明确的使用场景后再纳入范围。
