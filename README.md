# 趣味科学乐园

给 7～12 岁（小学二年级到六年级）孩子的互动科学网页：150 个动手小实验，覆盖物理、数学、化学、生物、天文、地理、工程、编程、信息科技、环境与健康 10 个科目。
纯静态文件，不需要安装任何东西；朗读用提前做好的音频，读不了中文的平板也能听。

**在线打开：https://handsun85s.github.io/fun-science/**

## 怎么打开

- **任何地方**：打开上面的在线网址，再“添加到主屏幕”。不用登录，不用电脑开着。
- **在这台电脑上**：双击 `index.html`，用 Chrome / Edge 打开。
- **在家里的手机、平板上，不联网也能用**：
  1. 在电脑上双击 `启动平板访问.bat`，会弹出一个黑色窗口，里面写着地址，比如 `http://192.168.x.x:8000`。
  2. 手机、平板连同一个 Wi-Fi，在浏览器地址栏输入这个地址。
  3. 用的时候不要关那个黑色窗口。再次双击启动文件会自动替换旧版本的窗口。
  - 第一次运行时，如果 Windows 弹出防火墙提示，勾选“专用网络”并点“允许”。
  - 需要电脑上装有 Node.js。服务器程序在 `tools/serve.js`。

## 朗读是怎么工作的

1. 设备自带中文朗读：直接用。
2. 读不了中文（不少平板是这样）：播放 `audio/` 里提前做好的音频。
3. 还没做成音频的文字、并且是用 `启动平板访问.bat` 打开的：由电脑现场合成。

**改了课程里的文字后**，在这台 Windows 电脑上重新生成朗读音频（只会生成变化了的句子）：

```
cd tools
npm install
node build-audio.js
```

## 怎么加新课

在 `js/lessons/` 里对应科目的文件中（比如 `physics.js`、`physics2.js`、`physics3.js`），照着现有的写一个 `Sci.register({...})`。新建的课程文件要在 `index.html` 里引入：

- `subject`：physics / math / chemistry / biology / astronomy / geography
- `level`：1～5（决定难度和推荐年龄，见 `js/core.js` 里的 `levels`、`ages`）
- `intro`、`goal`、`fact`、`quiz`：讲解、任务、知识点、题目
- `mount(api)`：实验本体。常用的有 `api.stage()` 建画布、`api.loop()` 动画、`api.pointer()` 鼠标/触摸、
  `api.button()` / `api.toggle()` / `api.slider()` / `api.choice()` 控件、`api.note()` 提示、`api.goalDone()` 完成任务。
  这些都在 `js/app.js` 的 `makeApi` 里。

新增一个科目：在 `js/core.js` 的 `subjects` 里加一项，再在 `index.html` 里引入对应的课程文件。

代码尽量兼容老版本浏览器（老平板），用到新功能时请在 `js/core.js` 开头的兼容层里补上。
