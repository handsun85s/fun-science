# 趣味科学乐园

给 7～12 岁（小学二年级到六年级）孩子的互动科学网页：160 个动手小实验，覆盖物理、数学、化学、生物、天文、地理、工程、编程、信息科技、环境与健康 10 个科目。
纯静态文件，不需要安装任何东西；朗读用提前做好的音频，读不了中文的平板也能听。

**在线打开：https://handsun85s.github.io/fun-science/**

首页的“实验搜索”支持查找名称、科目和介绍里的关键词，也可以用空格组合关键词（例如“物理 光”）。输入后会显示结果数量、难度年龄和已获星星，点结果直接进入实验；回首页保留本次搜索，点“清空”可重新查找。

新增十个对照实验位于 `js/lessons/comparisons.js`：先预测、只改变一个条件、记录两种结果，再依据证据选择结论。模型数值用于教学，不代替实际测量；猜错预测不影响完成任务。

每课包含：猫头鹰讲解（可朗读）→ 动手实验 + 任务 → “你发现了吗”知识点 → 两道小考验。
完成任务和答对题目都能得星星，答错后可以回看实验或知识点，纠正后仍能得星；每题只奖励一次。已答对的题和已排除的选项会保存，刷新后可接着学。答对后可点“听听为什么”朗读解析。
进度保存在本机浏览器里（不同网址、不同设备的进度是分开的）。

## 怎么打开

- **任何地方**：打开上面的在线网址，再“添加到主屏幕”。不用登录，不用电脑开着。
- **在这台电脑上**：双击 `index.html`，用 Chrome / Edge 打开。
- **在家里的手机、平板上，不联网也能用**：
  1. 在电脑上双击 `启动平板访问.bat`，会弹出一个黑色窗口，里面写着地址，比如 `http://192.168.x.x:8000`。
  2. 手机、平板连同一个 Wi-Fi，在浏览器地址栏输入这个地址。
  3. 用的时候不要关那个黑色窗口。再次双击启动文件会自动替换旧版本的窗口。
  - 第一次运行时，如果 Windows 弹出防火墙提示，勾选“专用网络”并点“允许”。
  - 需要电脑上装有 Node.js。服务器程序在 `tools/serve.js`。

## 朗读是怎么工作的

1. 设备自带中文朗读：直接用。
2. 读不了中文（不少平板是这样）：播放 `audio/` 里提前做好的音频。
3. 还没做成音频的文字、并且是用 `启动平板访问.bat` 打开的：由电脑现场合成。

**改了课程里的文字后**，在这台 Windows 电脑上重新生成朗读音频（只会生成变化了的句子）：

```
cd tools
npm install
node build-audio.js
```

## 怎么加新课

在 `js/lessons/` 里对应科目的文件中（比如 `physics.js`、`physics2.js`、`physics3.js`），照着现有的写一个 `Sci.register({...})`。新建的课程文件要在 `index.html` 里引入：

- `subject`：physics / math / chemistry / biology / astronomy / geography / engineering / coding / infotech / health
- `level`：1～5（决定难度和推荐年龄，见 `js/core.js` 里的 `levels`、`ages`）
- `intro`、`goal`、`fact`、`quiz`：讲解、任务、知识点、题目
- `mount(api)`：实验本体。常用的有 `api.stage()` 建画布、`api.loop()` 动画、`api.pointer()` 鼠标/触摸、
  `api.button()` / `api.toggle()` / `api.slider()` / `api.choice()` 控件、`api.note()` 提示、`api.goalDone()` 完成任务。
  这些都在 `js/app.js` 的 `makeApi` 里。

新增一个科目：在 `js/core.js` 的 `subjects` 里加一项，再在 `index.html` 里引入对应的课程文件。

代码尽量兼容老版本浏览器（老平板），用到新功能时请在 `js/core.js` 开头的兼容层里补上。

## 小考验回归检查

安装工具依赖后，在 `tools` 目录执行 `npm run test:quiz`。测试使用已安装的 Chrome 和独立浏览器数据，验证答错纠正、旧星星保留、刷新恢复、不重复奖励、解析朗读入口和手机排版；不会修改用户实际学习进度。可用 `TEST_BROWSER_PATH` 指定其他 Chromium 路径，用 `TEST_BASE_URL` 检查已部署站点。

## 用 Codex 继续开发

在 Codex 中选择这个项目文件夹，然后直接描述要新增的功能或遇到的问题即可。本项目的开发约定保存在根目录 `AGENTS.md`，方便新的聊天继续接手。

- 开始任务时先读取 `AGENTS.md` 和本说明，查看当前代码与 Git 状态。
- 本地预览运行 `node tools/serve.js`；仅查看网页不需要安装工具依赖。
- 课程文字变化时，重新生成朗读音频，并验证受影响的实验。
- 上传到 GitHub 需要可用的账号授权；认证状态不会因为导入聊天而自动恢复。若提示未登录，由账号本人完成 GitHub 登录授权，不向聊天发送密码或令牌。
- GitHub Pages 发布成功后，在原来的在线网址刷新。同步代码与更新聊天记录是两回事。

对照实验回归：在 `tools` 目录执行 `npm run test:comparisons`，检查两组实验记录、根据证据修正预测、重复操作不重复加星，以及手机和旧浏览器兼容性。
